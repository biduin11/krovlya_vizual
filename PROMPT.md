# Стартовый промпт для Claude Code

Скопируй текст ниже первым сообщением в Claude Code, открытом в этой папке.

---

Прочитай CLAUDE.md и prototype/index.html — это рабочий прототип 3D-визуализатора кровли (Three.js, один HTML).

Задача: перенести прототип в Next.js 15 + TypeScript + React Three Fiber (@react-three/fiber, @react-three/drei) + zustand, функционал 1-в-1, деплой на Vercel.

Требования:
1. Структура папок — как в разделе «Перенос в Next.js» в CLAUDE.md.
2. Геометрию (roofModel, slopeGeometry, spanAt, newell) вынеси в чистые TS-функции в lib/geometry и покрой тестами на vitest.
3. Шейдеры кровли и фасада перенеси без изменения логики (onBeforeCompile + customProgramCacheKey).
4. Только визуализация — никаких расчётов, площадей, смет, цен. Объект kit из прототипа не переносить.
5. UI на русском, адаптив: десктоп — панель справа, мобильный — сцена сверху, панель снизу.
6. После переноса сравни с прототипом: все 5 форм крыши, 3 материала, W>L и W<L, мобильная ширина.

Сначала покажи план по шагам, потом делай.
