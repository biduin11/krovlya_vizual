# Примерка кровли 3D

Прототип на Three.js: `prototype/index.html`.

## Запуск

Развёрнутая версия выдаёт HTML визуализатора только после входа. Для локального
запуска и Vercel нужны Node.js 24, Neon Postgres и SMTP-провайдер.

| Переменная | Значение |
| --- | --- |
| `APP_URL` | Канонический HTTPS-адрес приложения, например `https://roof.example.com`. Локально можно использовать `http://127.0.0.1:8765`. |
| `OWNER_EMAIL` | Почта владельца с доступом к админке. |
| `DATABASE_URL` | URL Neon с пулером (в имени хоста есть `-pooler`). Нужен серверу Vercel. |
| `DATABASE_URL_UNPOOLED` | Прямой URL той же базы Neon, без `-pooler`. Нужен только для миграций. |
| `SMTP_URL` | Строка подключения к SMTP, например `smtps://user:password@smtp.example.com:465`. Спецсимволы в логине и пароле кодируются как в URL. |
| `MAIL_FROM` | Адрес отправителя, разрешённый SMTP-провайдером. |

Локально экспортируйте переменные в окружение и выполните:

```sh
npm ci
npm run db:migrate
npm start
```

В Neon Console откройте проект `krovlya_vizual` и базу `krovlya_vizual`.
Получите оба URL в разделе Connect. Для обоих URL можно указать
`sslmode=verify-full` для проверки сертификата и имени сервера.

В настройках Vercel задайте `DATABASE_URL`, `APP_URL`, `OWNER_EMAIL`,
`SMTP_URL` и `MAIL_FROM`. Выполните `npm run db:migrate` с прямым URL
целевой ветки Neon в `DATABASE_URL_UNPOOLED` и разверните приложение.
Для тестовых деплоев используйте отдельную ветку Neon.
`vercel.json` публикует только каталог `public`; визуализатор загружает
серверная функция. Используйте адрес из `APP_URL` для входа и отправки ссылок.

## Как выдать доступ

1. Откройте `/login`, введите `OWNER_EMAIL`, откройте письмо и подтвердите вход.
2. В меню «Аккаунт» выберите «Управление доступом». Укажите почту получателя и
   отправьте приглашение. Ключ в письме действует 48 часов и погашается при входе.
3. После первого входа пользователь может запрашивать новые ссылки на `/login`.
   Они действуют 15 минут. Сессия длится до 30 дней.
4. «Отозвать доступ» аннулирует ссылки и сессии пользователя.

Доступ ограничивается в новом развёртывании. Для закрытого запуска удалите или
ограничьте прежние общедоступные деплои с HTML и отдельно опубликованный артефакт.
Если исходники доступны публично, любой сможет открыть свою копию визуализатора.

## Сохранение и ракурсы

- «Ссылка» сохраняет параметры дома и положение камеры в адресе. Открыв ссылку, пользователь получает тот же вариант. Для передачи другому человеку нужен адрес опубликованного сайта: локальный файл или localhost доступны только на вашем компьютере.
- Если буфер обмена недоступен, ссылку можно скопировать из появившегося поля.
- «Сохранить PNG» скачивает текущий ракурс с подписью материала, покрытия и RAL.
- Доступны ракурсы «Общий», «Спереди», «Сбоку», «Сверху», «Кровля». Выбор ракурса останавливает автоповорот.
- Повреждённая ссылка открывает стандартную конфигурацию; недопустимые параметры игнорируются.

## Профили кровли

«Монтеррей», «Каскад» и «Бавария» имеют поперечные ступени с шагом 350 мм. «Бавария» — по чертежу производителя: ширина листа 1135 мм, полезная 1020 мм, 4 волны на полезной ширине (шаг 255 мм), волна 44 мм, ступень ряда 30 мм, высота профиля 74 мм. Сечение: выпуклый гребень одной дугой (R ≈ 98 мм) без плоской вершины, скругление дна R60 и плоское дно около 36 мм. «Монтеррей» отличается округлой волной высотой 36 мм с шагом 183,5 мм и поперечной ступенью высотой 25 мм, «Каскад» — широкими плоскими гребнями, узкими впадинами и тонкими продольными канавками. У С21 и НС35 продольные трапециевидные рёбра с высотой и шагом 21 / 100 мм и 35 / 200 мм соответственно. Размеры описывают типовые профили, а продавцы и производители могут использовать свои варианты.

## Фальцевая кровля

«Фальц» — объёмные панели с шагом 515 мм и одинарным высоким замком по образцу владельца. Варианты полки: гладкая, два круглых ребра, две узкие плоские полосы, одна широкая полоса по центру. Вариант полки сохраняется в ссылке. Высота замка 30 мм и размеры рёбер приняты приблизительно; на образце указан только шаг панели.

## Фальцнастил

Отдельный профиль «Фальцнастил» воспроизводит широкие плоские панели, двойные продольные замки с глубоким центральным желобом до уровня листа и тонкие канавки по фото владельца. Замки имеют объёмную геометрию, в том числе на треугольных и вальмовых скатах. Шаг панелей — 330 мм. Высота замка по фото принята приблизительно, 30 мм. Профиль сохраняется в ссылке на конфигурацию.

## Мансардные окна

Окна можно перетаскивать мышью или пальцем по своему скату. Ссылка на конфигурацию сохраняет их позиции. При изменении формы, размеров, угла, свеса или количества окон снова применяется автоматическая расстановка.

## Вентиляционные выходы

В разделе «Элементы кровли» для каждого ската можно отдельно выбрать до 6 вентиляционных выходов и до 3 мансардных окон. Если места для выбранного количества недостаточно, визуализатор показывает, сколько элементов поместилось. Окна и выходы можно перетаскивать в пределах своего ската. Количество и ручные позиции сохраняются в ссылке.

## Проверки

На Node.js после установки зависимостей:

```powershell
npm test
```

Проверяются смещения вершин и карнизы пяти форм, обновление подписи, объединение пересборок, сохранение и валидация конфигурации, а также сценарии доступа с тестовой PostgreSQL и почтой. Эти проверки не заменяют визуальное тестирование WebGL.

## Производительность и ограничения

Металлочерепица имеет два уровня геометрии: до 32 000 треугольников на скат в общем виде и до 96 000 при приближении. В неподвижной сцене повторный рендер пропускается. Плотность меняется только после окончания движения камеры, чтобы не пересобирать сетку на каждом кадре.

Для ломаной крыши допустимый свес зависит от высоты стен и угла нижнего ската. Если карниз оказался бы ниже 1,8 м, свес уменьшается автоматически; UI показывает ограничение. Ссылка сохраняет фактически применённый свес.

Проверка в браузере: переключите пять форм и три материала, приблизьте/отдалите камеру, откройте «Кровля», проверьте высоту стен 2,6 м и угол 55° у ломаной крыши, сохраните PNG. На мобильном экране отдельно оцените FPS и чтение панели.
