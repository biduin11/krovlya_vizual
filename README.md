# Примерка кровли 3D

Прототип на Three.js: `prototype/index.html`.

## Запуск

Откройте HTML в современном браузере либо запустите статический сервер:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8765/prototype/ . Для загрузки Three.js нужен интернет.

## Сохранение и ракурсы

- «Ссылка» сохраняет параметры дома и положение камеры в адресе. Открыв ссылку, пользователь получает тот же вариант. Для передачи другому человеку нужен адрес опубликованного сайта: локальный файл или localhost доступны только на вашем компьютере.
- Если буфер обмена недоступен, ссылку можно скопировать из появившегося поля.
- «Сохранить PNG» скачивает текущий ракурс с подписью материала, покрытия и RAL.
- Доступны ракурсы «Общий», «Спереди», «Сбоку», «Сверху», «Кровля». Выбор ракурса останавливает автоповорот.
- Повреждённая ссылка открывает стандартную конфигурацию; недопустимые параметры игнорируются.

## Проверки

Без установки зависимостей, на Node.js:

```powershell
node --test tests/*.test.cjs
```

Проверяются смещения вершин и карнизы пяти форм, обновление подписи, объединение пересборок, сохранение и валидация конфигурации. Эти проверки не заменяют визуальное тестирование WebGL.
